# 期刊到藏校对册

馆藏编校人员用订购定义和来刊清册核对各订阅链。校对页以年度、卷号和期号展示应到、到藏、缺刊或争议及原始行，可按状态或订阅链筛选。

## 启动

```bash
docker compose config --quiet
docker compose up --build
docker compose exec -T app pytest -q
```

工作台默认地址为 `http://localhost:18443/`，接口文档在 `/docs`。使用 `SERIAL_LEDGER_PORT` 调整对外端口。归档写入 Compose 命名卷，普通停止及重启均保留。宿主运行可用 `python -m pip install -r requirements.txt` 和 `uvicorn app.main:app --port 18443`，本地数据库默认写入 `instance/`。

## 样例校对

1. 打开默认十一月补刊清单。预期 14 个期位，覆盖 7、缺刊 4、争议 3。另登记 3 件增刊。
2. 筛选争议，打开海岸观测 2025 年第 17 卷第 2 期。第 2、3 行同时覆盖该期，第 1 期仍然只有合期一项依据。
3. 切换验收清册，核对 14 个期位全部覆盖。可选择自备清册并粘贴同结构的 JSON。
4. 切换跨年合期清册。一件实物（如验收号 00033）同时挂接 2025 年第 4 期与 2026 年第 1 期，在藏实物只计一件；GEO 链一个边界期位保留争议，重复回传不二次计入。
5. 归档后进入证据寄送，重跑或下载凭证。凭证保存输入、规则版本、计算结果和原始行。

年度内可采用从 1 复位或跨年连排的期号。刊名按出版年度生效并映射到稳定订阅链。项目接受单年度内的合期；跨年度合期须登记出版方确认的出版说明，一件实物在说明覆盖的两个年度各挂一次期位依据，但馆藏按验收号只计一件。刊名沿革粒度为年。

### 跨年度合期裁决

同一验收号代表的实物跨越两个年度时，**两个年度都保留可追溯的同一实物依据，在藏只认一件**，而不是把它强行并入单一年度：

1. 采信前提是 `publication_notes` 中出版方确认的说明（编号、订阅链、年度区间、原文）。说明本身不合法（越订购段、编号重复、刊名不属于该链）时整份清册阻断。
2. 来刊引用说明编号后，卷号须对准起始卷、期号范围须对准两个年度的边界期位（逐年复位为末年号倒接首年号，如 `4-1`；连排为末年号接次年初号，如 `9-10`）。任一不符整条进入待复查，绝不部分采信。
3. 期位表在两个年度各自勾稽并显示同一验收号；`totals.holdings` 按验收号去重统计实物件数，因此一件跨年合期不会在两个年度各算一件。
4. 页面「跨年出版说明」面板展示采用的说明原文、涉及年度与卷号、已覆盖期位、争议期位及未核清原因；期位行对跨年依据加标记，原件面板保留原始行与说明编号。
5. 同一验收号重试仍按重复回传只计一次；归档以规则版本加输入摘要定位，跨年重跑不产生第二份档案、不丢记录。
